# Dedsafio 4 Addon

Repositorio que contiene el addon de Minecraft Bedrock Edition para el **Dedsafio 4**.

## Contenido

- `Dedsafio_4_addon.mcaddon` — Paquete del addon (comportamiento y recursos) listo para instalarse en Minecraft Bedrock.

## Instalación

1. Descarga el archivo `Dedsafio_4_addon.mcaddon` desde este repositorio.
2. Haz doble clic sobre el archivo (o ábrelo con Minecraft) para que se importe automáticamente.
3. Entra a un mundo existente o crea uno nuevo y activa el addon desde la sección de **Comportamiento / Recursos**.

> Si el archivo `.mcaddon` no se asocia automáticamente con Minecraft, puedes renombrarlo a `.zip`, extraerlo e importar manualmente las carpetas `behavior_pack` y `resource_pack` a `com.mojang/development_behavior_packs` y `com.mojang/development_resource_packs` respectivamente.

## Notas

- Compatible con Minecraft Bedrock Edition.
- Tamaño del paquete: ~46 MB.
