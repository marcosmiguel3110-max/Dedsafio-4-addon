# Dedsafio 4 Addon

Repositorio que contiene los addons de Minecraft Bedrock Edition para el **Dedsafio 4**.

## Contenido

| Archivo | Tamaño | Descripción |
|---|---|---|
| `Dedsafio_4_addon.mcaddon` | ~46.6 MB | Paquete principal del addon (comportamiento + recursos). |
| `asset.mcaddon` | ~99.7 MB | Recursos adicionales del addon. |

## Instalación

1. Descarga los archivos `.mcaddon` desde este repositorio.
2. Haz doble clic sobre cada archivo (o ábrelo con Minecraft) para que se importe automáticamente.
3. Entra a un mundo existente o crea uno nuevo y activa el addon desde la sección de **Comportamiento / Recursos**.

> Si el archivo `.mcaddon` no se asocia automáticamente con Minecraft, puedes renombrarlo a `.zip`, extraerlo e importar manualmente las carpetas `behavior_pack` y `resource_pack` a `com.mojang/development_behavior_packs` y `com.mojang/development_resource_packs` respectivamente.

## Notas

- Compatible con Minecraft Bedrock Edition.
- Se recomienda instalar primero `Dedsafio_4_addon.mcaddon` y luego `asset.mcaddon`.
- Los archivos superan los 50 MB (advertencia de GitHub) pero están dentro del límite permitido.
